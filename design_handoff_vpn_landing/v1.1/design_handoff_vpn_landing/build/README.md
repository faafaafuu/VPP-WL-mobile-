# Вёрстка главной темы — cleohop.ru (cyberpunk terminal)

## Файлы
- `index.html` — главная (лог, герой, 4 тарифа, «как это работает», примечания, статус-бар)
- `pay.html` — страница оплаты
- `styles.css` — вся тема: токены, компоненты, мобильная версия

Открывается как есть в браузере, без сборки. Шрифт — Share Tech Mono с Google Fonts.

## Что наведено в порядок
- **Сетка 4px.** Все отступы — переменные `--s1…--s12`. Вертикальный ритм: между секциями 48px (моб. 32px), внутри секции 14px, между строками 10–12px.
- **Одна высота контролов** — `--ctrl: 52px` для всех кнопок, полей, чипов монет и селекта сети. Больше нет рваных дропдаунов разной ширины.
- **Колонки тарифов фиксированы** (`1fr 110px 64px`) — цены и бейджи скидок выровнены по вертикали.
- **Порядок оплаты:** стейблкоины (USDT/USDC, 2 колонки) → сеть (отдельная строка-селект) → другая крипта (ETH/BTC/TON/SOL, 4 колонки) → карта (свой блок с бейджами).
- Инструкция — нумерованный список с висячим отступом (`28px 1fr`), номера не «прыгают».
- Шаги 1-2-3 подписаны, у каждой секции служебный лейбл `// …`.

## Мобильная версия (≤720px)
- Паддинги 40 → 18px, ритм 48 → 32px.
- Тариф перестраивается в 2×2: название/цена сверху, мета/скидка снизу.
- Монеты: 4 колонки → 2. Карта и кнопки — на всю ширину.
- Адрес кошелька переносится (`word-break: break-all`) вместо обрезки.
- Все тап-зоны ≥ 52px.

## Точки интеграции для бэкенда
- Тарифы ведут на `/pay?plan=1m|3m|6m|12m`.
- `pay.html`: смена монеты/сети должна пересчитывать сумму и адрес на сервере — сейчас в разметке JS только подсвечивает активный чип и копирует адрес.
- Форма email → `POST /bind-email`. Ссылки: `/recover`, `/terms`, `/privacy`, Telegram-бот.
- Статус-бар и лог в шапке — декоративные, данные подставлять не нужно.
